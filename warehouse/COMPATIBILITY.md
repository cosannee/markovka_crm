# Сверка рабочей схемы Supabase

Источник: результат warehouse_check, предоставленный пользователем. Это снимок структуры, не подтверждение применения миграции.

Подтверждено:
- crm_profiles содержит user_id UUID, role/name TEXT и active BOOLEAN с NOT NULL — необходимые поля совпадают.
- Александра: активный manager. Даша: активный director. Также 6 активных master. Новые роли не нужны.
- auth.uid() существует. Склад не заменяет crm_current_profile и не зависит от её SECURITY DEFINER.
- В storage.buckets/objects присутствуют поля для приватных фотографий.
- crm_stock отсутствует, crm-materials отсутствует, имена новых складских RPC свободны.
- В полученном отчёте нет существующих policies storage.objects, с которыми пересекались бы новые складские правила.

Дополнительные обязательные поля Storage есть в реальной схеме, но отчёт не содержит их default. Поэтому перед началом миграции добавлена проверка обязательных полей без default. Также проверяется включённый RLS storage.objects и отсутствие уже созданного склада. При несоответствии транзакция прекращается, ничего не применяется.

Не подтверждено этим отчётом: реальные права выполнения после установки, работа Storage API, сценарии пользователей на реальном Supabase и Safari/PWA. Их нужно проверить отдельно перед публикацией интерфейса.

Действие, требующее отдельного подтверждения: применить 001-warehouse.DRAFT.sql, создав только складскую схему, проверяющие доступ функции и приватный bucket с правилами. Заказы/финансы/зарплаты не изменяются. Публикация сайта — отдельный последующий шаг.

Пользователь сообщил: «Success. No rows returned» после запуска установки. Это подтверждение выполнения со стороны пользователя; независимая проверка установленных объектов и прав пока ожидается. Для неё подготовлен 002-verify-READ-ONLY.sql. Интерфейс не опубликован.

Получен warehouse_verification: 9 таблиц, RLS везде true, прямые SELECT/INSERT/UPDATE/DELETE authenticated запрещены, anon SELECT запрещён, USAGE схемы anon/authenticated запрещён. Три RPC SECURITY DEFINER с пустым search_path; anon EXECUTE запрещён, authenticated разрешён. Bucket crm-materials приватный, 5 МБ, JPEG/PNG/WebP; storage RLS включён, две ограниченные складские policies. Пять категорий, остальные проверенные счётчики нулевые. Структурная установка подтверждена. Сквозные проверки входа и Storage API ещё не выполнены.
